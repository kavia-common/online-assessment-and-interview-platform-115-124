# Web Frontend

React web frontend for the online assessment and interview platform.

## Employee Module Updates

- Assigned Reviews list and Review Detail with Evaluation Form (placeholders).
- Interviews page with schedule table and notes.
- Chat UI stubs (sidebar, window, message input) with WebSocket placeholder adapter.

Environment:
- To enable chat WebSocket in future, set REACT_APP_WS_URL or configure `wsBase` via `src/config/env.js` (do not commit secrets).

## Development

- npm start: run dev server
- npm run build: production build
- npm test: run tests
